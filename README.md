# 白膜预演台 · WhiteStage

轻量级、纯本地的网页版白膜预演（previz）工具。用一个无限延展的纯色舞台快速摆机位、人偶、道具和背景，支持多机位分屏、关键帧动画与视频导出。

当前版本：**M6 完成版（本地版 v0.1）**：M2-C 多图背景板、M3 多机位分屏 / 自由布局 / 实时景深、M4 时间线、M5 WebM / MP4 / MOV / FLV / PNG 导出、M6 撤销 / 性能 / 发布打包、本地 Agent 与 AI 配置预留。验收记录见 [ACCEPTANCE.md](ACCEPTANCE.md)。

---

## 快速开始

**方式一：双击 `启动.bat`**

首次运行会自动安装依赖，然后启动：

- 应用：`http://127.0.0.1:5175`
- 本地 Agent 桥接：`http://127.0.0.1:8787`

浏览器会自动打开应用。关闭应用窗口即停止 Web 服务；Agent 在单独窗口运行，也可以单独使用 `启动Agent服务.bat`。

**方式二：手动**

```bash
npm install
npm run dev
# 另开一个窗口
node scripts/agent-bridge.mjs
```

打开 http://127.0.0.1:5175 。

> 建议使用最新版 Chrome / Edge（需要 WebGL2、IndexedDB、WebCodecs 支持）。
> 工程数据只保存在本机浏览器里；AI Key 也只保存在本机，当前不会联网。

### 本地 Agent / AI 接口

- 外部 Agent：`POST http://127.0.0.1:8787/rpc`，默认 Token `whitestage-local`，命令表与示例见 [AGENT.md](AGENT.md)。
- 页面内「场景 → 本地 Agent」可以看到端口和连接状态；「AI 接口（预留）」可以保存 Base URL / 模型 / API Key。
- 当前只预留 AI 配置和接口类型，不会发送 API Key 或发起网络请求；后续聊天、图片/文件上传、指令控制会复用同一套 Agent 命令总线。

### 正式发布包

```bash
npm run package:portable
```

会先清理并重建 `dist/`，然后生成：

- `release/WhiteStage/`：可直接运行的发布目录，不需要 `npm install` / Vite；
- `release/WhiteStage-v0.1.zip`：标准版（需要 Node.js）；
- `release/WhiteStage-v0.1-portable.zip`：便携版（内置 Node.js 运行时）。

下载已构建版本：

- [GitHub Releases](https://github.com/Ccm-Tim/whitestage/releases/latest)

> 源码仓库不提交 `node_modules/`、`dist/`、`release/`、浏览器测试缓存和开发截图；下载包请从 Releases 获取。

发布目录包含：

- `启动.bat`：同时启动静态站点（5175）和 Agent 桥接（8787）；
- `启动Agent服务.bat`；
- `app/`：Vite 生产构建；
- `scripts/serve-release.mjs`：纯 Node 静态服务器；
- `scripts/agent-bridge.mjs`；
- `README.md` / `AGENT.md` / `版本说明.txt`。

> 发布版只需要 Node.js；浏览器仍需 Chrome / Edge（WebGL2 / WebCodecs）。

## 操作

| 操作 | 说明 |
| --- | --- |
| 左键点击 | 选择机位 / 人偶 / 道具 / 取消选择 |
| 右键拖动 | 旋转编辑器视角 |
| 中键拖动 | 平移视角 |
| 滚轮 | 缩放 |
| `Q` / `W` / `E` | 选择 / 移动 / 旋转工具 |
| 方向键 | 选中机位或对象后前后左右微调 |
| `Shift` + `↑` / `↓` | 机位或对象升降（也可用 PageUp / PageDown） |
| 方向键步长 | 「场景 → 编辑器」里调整（0.01–2 米） |
| `F` | 聚焦当前选中的机位或对象 |
| `Esc` | 取消选择 |
| `Ctrl+S` | 保存 |

拖动预览窗顶部可移动，右下角可缩放；顶部眼睛按钮隐藏，左侧工具栏的眼睛按钮可重新显示。

### 目标锁定

1. 选中一个机位，在右侧「目标锁定」里点「锁定目标…」。
2. 在场景里点击另一个机位、人偶/道具，或点击地面上的任意一点。
3. 目标上会出现蓝色锁定标记，之后移动该机位时镜头会一直对准目标。
4. 点「重新选择」换目标，点「取消锁定」解除；按 `Esc` 可退出选择状态。

目前支持机位、人偶/道具、地面坐标点、舞台中心作为目标；锁定到人偶/道具后，移动对象时镜头会跟随。

### 机位管理

- 机位名称在「机位参数 → 名称」里修改，离开输入框或按回车生效。
- 名称不能为空，也不能与其它机位重名（不区分大小写、忽略首尾空格）；重名时会原地提示，不会保存。
- 改名后，预览窗顶部的机位下拉、机位列表、目标锁定标签会同步更新。
- 删除机位会弹窗确认；如果别的机位锁定在它身上，会提示并自动解除。删除最后一个机位时预览窗会没有画面。
- 新建机位会取「镜头」已有最大编号 +1（例如已有镜头 2、镜头 3，新建为镜头 4），不会因为删除第一个机位而重复。

### 人偶与道具

1. 右侧切到「对象」标签，对象库按「人偶 / 动物 / 植物 / 昆虫 / 建筑 / 车辆」分类；点卡片即可添加。
2. 人偶有成人男 / 成人女 / 男孩 / 女孩四种体型，支持身高、训练服颜色、头/手颜色、鞋子颜色和面部五官开关，以及站立 / 行走 / 奔跑 / 坐姿 / 挥手 / T 型六种简单姿势。
3. 「全身同色」会让头、手、鞋都跟训练服同色；「恢复白膜配色」回到浅色头手 + 灰色鞋。
4. 道具涵盖狗、猫、鸟、马、树、灌木、花、蝴蝶、房屋、塔、汽车、巴士、自行车；支持颜色、姿势（动物）和大小。
4. 在场景里点选对象，或用「场景对象」列表选择；选中后会出现蓝色包围框和坐标箭头。
5. 方向键沿对象朝向微调，Shift+↑↓ 或 PageUp / PageDown 升降；也可以在对象参数里直接输入坐标，或拖动坐标箭头。
6. 「复制对象」会复制当前参数并轻微偏移；「删除对象」会弹窗确认，若有镜头锁定在它身上会自动解除。
7. 镜头目标锁定支持人偶 / 道具；对象移动时镜头会自动跟随。
8. 「整体缩放」有滑杆和数值输入框，输入框可以填 0.01–1000× 的任意值；人偶身高和整体缩放会叠加。
9. 需要让人偶 / 道具穿到白色地面以下时，打开「允许穿地」，再调位置 Y（或 Shift+↓）；「回到地面」把 Y 归零，「恢复默认位置」回到对象添加时的位置并关闭穿地。
10. 头部、双手、双脚在模型里命名为 head / leftHand / rightHand / leftFoot / rightFoot，方便后续 AI 分割、识别和替换；颜色只是辅助，稳定的关节结构和部件语义更重要。

> 当前姿势是整体预设，逐关节编辑器、武器和自定义角色库规划在 M2-D（技术上可实现，不是不能做）。

### 角色编辑器

1. 选中一个人偶 → 对象参数顶部点「编辑角色」，打开独立编辑窗口。
2. 左侧是 3D 预览，右侧选择关节：脊柱、脖子、头、左右肩、左右肘、左右髋、左右膝，用 X / Y / Z 滑杆调整。
3. 也可以直接在左侧**点击身体部位**选中关节，蓝色小圆点是关节位置；选中后拖动旋转手柄即可调姿，滑杆用于精确微调。
4. 「快速姿势」提供站立 / 半蹲 / 坐地 / 趴下 / 英雄落地五个起点；「整体 / 落地」可以继续调整体高度、前后、俯仰、朝向和侧翻，用来做贴地、坐地、侧躺等动作。
5. 「显示关节节点」和「显示旋转轴」可以分别隐藏 / 显示蓝色关节点与旋转手柄；关闭旋转轴后仍可用滑杆调关节。
6. 支持「左右镜像」「重置当前关节」「重置全部」；可以同时改身高、训练服 / 头手 / 鞋颜色和面部五官。
7. 点「保存到我的角色」，输入的角色名会进入对象页的「我的角色」；当前人偶会立即套用这个姿势。
8. 「我的角色」里可以：
   - 点角色卡片添加到场景；
   - 导出 `.wsc.json` 分享；
   - 删除（二次确认）；
   - 「导入角色」接收别人导出的 `.wsc.json`。
9. 系统自带的人偶在对象库里，固定不可删除；自定义角色只出现在「我的角色」。
10. 编辑器目前从站姿开始，不会自动带入“挥手 / 奔跑”等预设姿势；武器和动物关节编辑在后续 M2-D2 / M2-D3。

### 武器

1. 在角色编辑器右侧「武器」里选择类型：剑 / 棍 / 刀 / 手刀 / 手枪 / 步枪，或「无」。
2. 选择左手或右手；武器会挂在该手的手部节点，随肩、肘和整体姿势一起转动。
3. 可以调「武器缩放」和「握持 X / Y / Z」，让剑刃 / 枪口朝向你想要的方向。
4. 保存自定义角色时武器会一起保存；对象库「我的角色」里再添加时，武器仍会带着。
5. AI 部件 ID / Mask 导出会把武器作为独立的 `weapon` 部件输出。

> 每个角色当前只能带一件武器，且是程序化基础模型，不是精细武器资产；暂不支持双手持握或手指级握持。

### 时间线 / 关键帧

1. 底部时间线可以拖动 / 点击定位，或直接输入**帧** / **秒**跳转。
2. 点图钉记录当前帧关键帧；再次点击是更新当前帧。图钉会出现在时间线上，点图钉可跳转。
3. 「自动关键帧」打开后，移动相机 / 对象会自动在当前帧打点；「吸附」拖动时吸附到附近关键帧。
4. 空格播放 / 暂停；播放到结尾会回到 0；逐帧用播放条两侧按钮。
5. 时间线长度可改（12–3600 帧）；删除当前帧关键帧或清空全部。
6. 关键帧会随工程保存。当前插值通道是相机与对象的位移 / 旋转 / 缩放 / 焦距 / 光圈 / 对焦距离，线性插值；关节 / 姿势关键帧后续补充。

> 时间线预览会直接更新场景的当前状态，所以保存时保存的是当前帧状态；关键帧本身会完整保留。

### 多图背景板

1. 在「场景 → 背景」点「多图背景板」，一次选择多张本地图片。
2. 图片会按各自比例、以默认 4m 宽横向拼接成平面背景板，自动关闭网格。
3. 上方缩略图选择某一张，调「板位置 / 板宽 / 板旋转」；「按宽度横向拼接」会重新从中心向左右排列。
4. 「曲面角度」可把整组板弯成 0–360° 的弧，180° / 360° 会围绕舞台；「接缝羽化」让相邻图片边缘透明过渡。
5. 「按文件名排序」用自然序号排列（1 / 2 / 10），再重新拼接；适合 `01.jpg`、`02.jpg` 序列。
6. 「锁定背景板」后禁止改板位置 / 宽度 / 曲面 / 羽化 / 排序，避免拼接好的背景被误改。
7. 可继续「添加图片」、删除当前板，或恢复纯色背景。
8. 多图资源会随 `.wsp` 工程导出；导入 / 打开时会检查所有图片是否齐全。

> 序号排序是按文件名自然排序，不是独立的“模板文件”系统。

### 多机位分屏预览

1. 预览窗顶部选择单机位 / 双机位 / 四机位 / 五机位。
2. 分屏时每个格子左上角单独选择机位；四机位是 2×2，五机位是 3×2 并留空右下角。
3. 「自由分屏」可选 1–3 列、1–2 行；拖动格子间分隔线调整比例，靠近 25% / 50% / 75% 会自动吸附。每格单独选择机位。
4. 空格播放 / 暂停与时间线共用，分屏里每个机位同步播放；导出缩略图仍使用主预览机位。
5. 机位「景深」里可开景深、调光圈和对焦距离；每个分屏格子按自己的机位虚化。

> 景深是屏幕空间近似，不是物理光学的散景形状；视频导出暂不包含分屏与景深后处理。

### 视频导出

1. 顶部「导出视频」打开导出窗口。
2. 选择 WebM、MP4 / MOV（H.264）、FLV（H.264）或 PNG 序列 zip。
3. 「画面来源」可选择主预览机位，或当前分屏布局（逐格合成，包含每格机位的实时景深）。
4. 设置分辨率、帧率、码率、起止帧；默认导出完整时间线。
5. 点「开始导出」，会离线逐帧渲染并显示进度；完成后自动下载。
6. 编码依赖 Chrome / Edge 的 WebCodecs；不支持时请用 PNG 序列。
7. MOV 使用 H.264/ISO 兼容封装，个别严格 QuickTime 工具可能要求转码；FLV 为单路 H.264、无音频。

### 撤销 / 重做

- 顶部撤销 / 重做按钮；
- `Ctrl+Z` 撤销，`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做；
- 相机 / 对象拖动、背景板、舞台、关键帧等主要编辑都会进入历史；
- 连续拖动合并为一次，避免每一帧都产生历史；
- 撤销后工程变为未保存状态，保存即可落盘。

### AI 部件 ID / Mask 导出

1. 右侧切到「对象」标签，找到「AI 辅助导出」。
2. 点「导出部件 ID 色 / Mask」，按当前预览机位导出所有可见人偶。
3. 下载的 zip 里包含：
   - `part-id.png`：每块部件用唯一纯色表示，黑色为背景；
   - `masks/*.png`：每个部件的 mask，白色为部件、黑色为其他区域；
   - `parts.json`：对象名、部件名（head / leftHand / rightFoot / weapon 等）、颜色、对应 mask 文件；
   - `README.txt`：使用说明。
4. 只包含当前预览机位内可见的人偶；道具、背景、网格和地面不会进入 ID/mask，被遮挡的部件在对应 mask 中为空。
5. 颜色只是分割索引；AI 替换时请以 mask 和 `parts.json` 为准。

> 这是按“部件”生成的可见 mask，不是深度图或法线图；需要更多通道（深度、法线、部件 ID 序列）可以后续扩展。

### 背景图片与全景

1. 场景 → 背景 → 「上传背景图」选择图片。
2. 应用前会弹窗确认类型，按宽高比给出建议，但始终由你确认：
   - **普通 2D · 屏幕贴片**：永远正对镜头，每个机位都满幅，可调水平/垂直偏移、缩放、旋转；没有视差，适合天空 / 背景贴片。
   - **普通 2D · 实体背景板**：放进 3D 场景，有视差，可调 X / Y / Z 和宽度，适合放在人物身后。
   - **360° 全景**：等距柱状全景，任意机位环视都正确，可调水平旋转。
   - **180° 全景**：素材放进 360° 环境的左半边，背面用浅色补齐。
   - **星球全景 → 360°**：近似逆投影展开，边缘可能有拉伸，建议应用后在预览窗环视检查。
3. 「更换图片」换一张，「恢复纯色」回到白膜 / 绿幕 / 蓝幕。
4. 全景 / 图片背景默认关闭网格，避免网格铺满照片；需要摆放时可在「舞台」里打开，网格只会在舞台附近径向淡出。
5. 全景背景的「地面贴合」会上下移动照片地平线，让全景地面尽量落到人物脚下；「干净全景对位」会一键关闭网格和局部白色地面，避免 3D 辅助地面和照片地面互相打架。
6. 全景照片的地面是拍死的 2D 画面，3D 网格不可能完全贴合；需要降低机位到接近拍摄者眼睛高度、移动对象，并结合「对象 → 整体缩放」调整人偶大小。
7. 「舞台 → 网格粗细」可调线条粗细；「局部白色地面」会在舞台中心垫一块白色地面，方便在花哨的全景上看清网格，仅编辑器显示。
8. 背景下勾选「仅预览显示背景」后，工作台切回白膜 + 网格，背景只在预览窗和导出中出现。
9. 全景支持水平旋转、地面贴合（俯仰）、翻滚校准。
10. 背景图片会存进 IndexedDB，并随 `.wsp` 工程一起打包到 `assets/`。

### 镜头模板

1. 选中机位，在右侧「镜头模板」下拉里选择「系统预设」中的任意一个，会立即套用焦距、传感器、光圈和对焦距离。
2. 想保存自己的设置：调好参数后点「保存当前」，输入名字即可进入「我的模板」。
3. 选中「我的模板」后可以「重命名」「导出」「删除」；删除会弹窗确认，系统预设没有删除 / 改名入口，固定不可删。
4. 分享给别人：点「导出」得到 `.lens.json` 文件；对方在镜头模板区域点「导入模板」选择该文件，模板会加入「我的模板」并立即套用到当前机位。

> 光圈与对焦距离会随模板保存，但景深虚化效果要到 M3 才可见；当前能立即看到的是焦距 / 传感器带来的构图变化。

## 工程格式

`.wsp` 是一个 zip 容器：

```
project.json    工程数据（schemaVersion = 1）
manifest.json   导出信息
thumb.jpg       缩略图（可选）
assets.json     背景资源清单（可选）
assets/         背景图片等资源
```

工程数据同时保存在浏览器的 IndexedDB（数据库名 `whitestage`）中。清除浏览器站点数据会连同本地历史一起删除，重要工程请先导出 `.wsp` 备份。

## 技术栈

- React 19 + TypeScript + Vite 8
- Three.js 0.187（WebGL2）
- Zustand + Immer（状态）
- idb（IndexedDB）、fflate（zip）
- 后续导出将使用 WebCodecs + mediabunny，ProRes / FLV 走 ffmpeg.wasm

```

  core/        类型、常量、数学、默认工程
  storage/     IndexedDB 与 .wsp 读写
  store/       全局状态与动作
  engine/      Three.js 场景、机位、坐标箭头、预览渲染
  ui/          开始页、编辑器、属性面板、预览窗、时间线占位
  styles.css   设计系统与全部界面样式
public/        图标等静态资源
scripts/       开发期截图 / 交互验证脚本（不属于应用运行时）
```

## 已知限制

- 每个角色当前只能带一件武器，且武器是程序化基础模型；暂不支持双手持握、手指级握持或导入外部武器模型。
- 人偶与道具是程序化低模，不是精细角色资产；逐关节编辑器和自定义角色库已开放，武器在 M2-D2，动物关节 / 外部模型导入在后续评估。
- 角色编辑器目前从站姿开始，预设姿势不会自动继承；但提供了半蹲 / 坐地 / 趴下 / 英雄落地等快速姿势和整体根节点控制。自定义角色导出为参数化 `.wsc.json`，不包含外部模型文件。
- 头部、手、脚有独立颜色和部件命名；AI 识别/替换不能只依赖颜色，还需要稳定的关节结构、部件语义和一致的相机/渲染流程。
- AI 部件 mask 是当前预览机位下的可见 mask，被遮挡部分为空；需要完整部件 mask 或深度/法线通道时再扩展。
- 图片 / 360 / 180 / 星球背景已开放；180° 的背面补色目前固定为浅色，星球展开是近似算法。
- 撤销历史最多 30 步，只在当前工程内有效；关闭 / 打开工程会清空历史。
- 正式发布包只包含生产构建和 Node 静态服务器，不包含源码、node_modules 或 Vite；需要 Node.js 才能启动。请通过 `npm run package:portable` 本地生成，或从 GitHub Releases 下载。
- 视频导出支持 WebM / MP4 / MOV / FLV / PNG 序列；MOV 是 H.264/ISO 兼容封装，严格 QuickTime 工具可能要求转码；FLV 为单路 H.264、无音频。
- 所有视频导出当前都没有音频轨道；景深是屏幕空间近似。
- 多机位分屏已开放，含自由列/行比例与吸附；景深为屏幕空间近似，不是物理散景。
- 多图背景板已支持平面 / 曲面、接缝羽化、文件名顺序和整板锁定；多图会在工程里保存缩略图 base64，工程文件会变大。
- 时间线目前是**场景级全局关键帧**：每一帧保存所有相机与对象的变换快照，再线性插值；还不是每个对象独立轨道 / 贝塞尔曲线。
- 关节 / 身体姿势、可见性、颜色暂不参与插值；可见性按关键帧就近切换。
- 全景照片的地面尺度在拍摄时已经固定，3D 网格 / 地面不可能和照片里的地面完全重合；「地面贴合」+ 降低机位 + 隐藏网格 / 白地是当前的处理方式，真正的地面接触需要深度或三维重建。
- 人偶支持身高和整体缩放（0.01–1000×），但 2D 全景没有深度，放大后仍需要手动对位；道具大小同理。
- 穿地后对象在编辑器里可能被白色地面/局部白色地面遮住，可临时关闭这些辅助层查看；预览/导出本来不包含白色地面。
- 「局部白色地面」和网格都是编辑器辅助层，不会出现在预览 / 导出里。
- 2D 屏幕贴片是平面贴片，没有视差；需要视差请用实体背景板。
- 预览窗当前为单画面；多机位分屏与自由拼接在 M3。
- 镜头模板里的光圈 / 对焦距离已保存，但景深虚化在 M3 才可见。
- 视频导出在 M5；时间线在 M4；多机位 / 景深在 M3。
- 更换背景时旧图片资源暂时保留，后续会加“清理未使用资源”。
- 需要 Chrome / Edge；Safari 的 WebCodecs 与 IndexedDB 行为未做适配。
